# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2   | :x:                |

## Reporting a Vulnerability

Please report security issues privately via [GitHub Security Advisories](https://github.com/tejus3131/md/security/advisories/new)
or email [tejus3131@tejusgupta.dev](mailto:tejus3131@tejusgupta.dev).

Do **not** open a public issue for vulnerabilities.

You can expect an initial response within a few days. If the report is confirmed,
we will work on a fix and credit you if desired.
